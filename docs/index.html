Measuring lossless compression for LLM KV caches

An extensible benchmark effort for BF16, FP8 and future KV cache formats. Our goal is to help practitioners select codecs based on reproducible compression ratio, CPU encoding cost, GPU decoding performance, and cache-layout constraints—across LMCache and other backends.

Where the benchmark is heading

Multiple numerical formats

BF16, FP8 E4M3FN/E5M2 and additional KV data types.

Reproducible codec evaluation

Compression ratio, CPU encoding throughput, byte-exact reconstruction and GPU decode when supported.

Backend-agnostic integration

Adaptable to LMCache or other systems, accounting for their real chunk and frame layouts.

The benchmark harness and machine-readable results are planned for a later release. This first publication shares the technical study and aggregate observations.
